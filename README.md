##　1. サービス概要

- 登録不要で使えるもの：認知症の簡易チェックのみ
- 登録が必要なもの：日々の記録の入力・保存、週間カレンダーでの振り返り、PDF出力

- 家族の小さな変化が気になり始めた初期段階の人に向けた、登録不要で使える記録、お守りアプリ。
血圧や薬の細かい管理をあえて削ぎ落とし、1日1回、大まかな３項目の記録と、PDF連携で、家族の孤独と負担を減らしています。
- 【誰の】最近、親の物忘れ等の変化に気づきつつも、まだ現実を受け入れたくない初期段階の家族
- 【どんな課題】従来の介護アプリは細かな入力や毎日のバイタル測定等の記録があり多忙な家族には負担が多く挫折してしまう。
- 【どう解決するか】登録不要の認知症チェックで心理的ハードルを下げ、日々の記録は1日1回、大まかな３項目に徹底的に絞ることで続けやすさを担保。さらに、蓄積したデータはケアマネジャー等への連携PDF出力に活用し、介護をする家族を支えます。

##　 2. このアイデアはどこから生まれたか

- ７年間介護の現場で働いている中で、日々の仕事量の多さと人手不足で、目の前のケアをこなすだけで精一杯の現実を目の当たりにしました。その中で紙の手続きや電話での連絡など、昔ながらの非効率な業務が残る現場の限界を知る一方で、２４時間３６５日自宅で介護を背負わなければならないご家族の負担や孤独感は、現場の比ではないことを痛感していました。
介護をする家族ににとって、日々の様子や変化を記録しておくことは大切だとわかっていても、毎日の細かな記録をつけること自体が、日々の介護に追われるご家族にとって大きな負担になってしまうのも事実です。
だからこそ、タップだけで直感的に記録できる、必要最低限の項目に絞ることで、忙しい日常の中でも無理なく続けられる仕組みにしました（より細かく残したい場合はメモ機能で対応できます）。
自宅で介護をする家族が、この手軽なアプリで日々の変化を無理なく記録し、必要な時にはPDFで専門職や関係者へスムーズに提示できる。そうすることで、家族が抱える負担や不安を軽減できるのではないかと思ったのが、このアプリを作るきっかけです。

- 私は感情的な寄り添いよりも全体を俯瞰し、論理的に優先順位をつけて物事をうまく回すことを優先してきました。
ここで少しの手間を怠ると、後からより大きなトラブルや余計な業務が返ってくるという非効率さや、変化に気付けずに防げたはずの事態は起きる構造に、強いもどかしさを感じていました。
だからこそ、個人の記憶や曖昧な連絡に頼るのではなく、家族が日々の小さな変化に自然に気づけ、その記録をPDF等でケアマネジャーへスムーズに共有することで、利用者、家族、専門職の連携がうまく回る仕組みを作りたいという思いがこの課題に目を向けたのさせたのだと思います。

## 3. 課題の整理（表面的になっていないか）

- 家族間や外部との連絡が紙ベース、ノートや電話などアナログな方法に頼っており、共有に無駄な時間と手間がかかっていること。

- 解決したい課題：施設に預けられないなど、在宅で認知症の親の介護を担わざるを得ない家族が、日々の小さな変化や不安を1人で抱え込んでしまう構造です。紙のニートや記録に頼ることで変化のサインを見逃したり、いざケアマネジャーや病院に相談する際に今の状態をうまく伝えられず適切なサポートが受けられないという非効率さと情報の分断を解決したいと考えています。

## 4. 想定ユーザーについて

### 想定しているユーザー
- 年齢：50代〜60代
- 理由：働きながら、80代前後の親のちょっとした変化や見守りに直面しやすい年代だからです。親の体調や物忘れの変化にどう向き合うか、いつ受信や相談をすべきかという迷いや不安を抱えやすい状況にあります。

- 生活・状況：親の変化が気になり始めた初期段階の家族（例、医療や介護の知識があっても、家族の初期の変化には気付きにくく迷いを感じる50代〜60代の家族など）。
- 理由：気になり始めた段階でいきなり病院や介護に踏み切る前に、まずは日々のちょっとした変化を記録することから始めてみる習慣を作るためです。記録を残しておくことで、状況が進んだ際や必要なタイミングでPDFなどを通じて専門職へスムーズに共有しやすくなります。

- 環境：日中は仕事で忙しく、帰宅後も家事や家族の対応に追われ、記録のためにまとまった時間を取るのが難しい環境。
- 理由：時間が取れない環境でも、まずは記録してみようと思えるよう、紙のノートではなくスマホから直接的なタップや最低限の入力で残せる仕組みにします。負担を減らしながら継続できる形を目指します。

- 自分とユーザーの距離：身近な誰か
- 85歳で両親ともに認知症を患い、その介護に直面している家族がいるからです。

- まず最初に使ってくれそうな人：働きながら高齢の親の日々の介護で不安を抱えている50代〜60代の家族（かつて私の母がそうであったようば立場の方々）です。
- その人は、どんな場面でこのアプリを思い出すか：最近、親の認知症の症状が進んでいる気がする、とモヤモヤしたとき。
- 今の生活の中で、代わりに使っているものは何か：紙のノートやメモ用紙、個人のスマホの機能、あるいは、毎日の細かな記録をつけること自体負担になるため記録自体を諦めて、自分の記憶に頼っている状態。
- それを置き換えてまで使う理由はあるか：紙のノートや記憶に頼る方法では、毎日の記録が手間で続きませんが、このアプリならタップだけで直感的に記録でき、必要最低限の項目に絞られているため、無理なく続けられるから。登録不要のチェック機能など最初のハードルが低い、一方でいざという時には記録したデータをPDFにして専門職へスムーズに提示、共有できるという、メリットがある。

- どんな場面・困りごとがきっかけで、このサービスを知る・思い出すか：親の介護をしている家族が親の認知機能に変化を感じたとき。「最近、親の物忘れやいつもと違う様子が増えた」「もしかして、認知症の初期の症状かもしれない」と不安を感じたとき。
- 最初の一歩（登録・導入）で、ユーザーは何をする必要があるか：重い登録作業を最初に行うのではなく、まずは「今の症状から認知症の可能性を割り出す簡易チェックを登録無しで手軽に試すことで現状を知り、記録を残していこうと自然に登録、利用へ繋げる仕様にしている。
- 利用を続ける理由は何か？（習慣・必要性・価値）：タップだけで直感的にできる「必要最低限の記録」を続けることで、親の小さな変化のサインを見逃さずキャッチできること。また、いざという時にその記録を「PDF」としてケアマネジャー等へスムーズに提示でき、相談や連携が楽になるというメリットがあるため。

- 既存サービスがある中で、なぜ満足できなかったのか：アンバリーなどの既存のアプリは「家族間でのリアルタイム共有」や「細かな日々の入力」を前提としているため、1人で介護を背負う家族にとって記録をつけること自体が毎日の大きな負担になってしまうという本質的な課題を解決しきれていない点に物足りなさを感じていました。また、アプリ自体が重く感じたり、設定や運用に手間がかかる点がハードルになっていました。
- どこに違和感があったのか：既存の介護アプリは「福祉」「介護施設」「病院のカルテ」を連想させる事務的で重苦しいデザインが多く、アプリを開くこと自体が介護の現実を突きつけられるようで少し気が重くなるという心理的な違和感がありました。また、「自分はまだそこまで大げさな介護をしていない」と感じる人が最初から登録や細かな入力を強いられる設計になっているため、最初の段階でつまずいている人に届きにくい構造になっていることに違和感がありました。

- 私のアプリの差別化ポイント：【どんな人】「最近親の物忘れなどの変化が気になりつつも、まだ介護を認めたくない初期段階の家族」
- どんな瞬間：「いざ情報を調べたりアプリを検討したものの最初から会員登録や細かな入力がめんどくさくなり、利用を諦めてしまう最初の瞬間」
- このアプリがどう助けるか：「記録をつけましょうと身構えさせるのではなく登録不要で認知症チェックを遊び感覚で試せる体験を用意しました。これによりアプリを入れる心理的ハードルを下げ、結果を自分の記録として残しておきたい、いざという時にPDF化したいとスムーズに登録へ繋げることができる」

## 6. このサービスで提供したい価値

- 行動の変化：とりあえず今の状態をチェックしてみようと登録不要でアプリを試してもらえる。
- 気持ちの変化：結果を記録をしておいた方が後々便利なのかなと思ってもらえる。
- 考え方の変化：記録をすることで面倒なものからいざという時の安心材料として自然に継続できる。

- このサービスは親の変化に戸惑う初期の家族が、遊び感覚のチェックから自然に記録を残しいざという時の安心を手に入れられるサービス

## 7. このアプリで実現すること

### UI・デザイン方針
- 夜の記録で目が疲れないためのダークトーンのUI
- ユーザー自身で選べるライト表示への切り替え機能

### MVPで作る機能
- 登録不要で試せる認知症の可能性チェック機能
- 登録後すぐにニックネーム入力ページへ遷移
- 日々の簡単な記録（1日1回・3項目＋メモ）の入力
- ニックネームでの登録・利用（本名不要で心理ハードルを下げる）
- 記録完了時の「記録しました」の表示
- 週間カレンダー形式での記録確認・振り返り機能
- チェック結果や日々の簡単な記録やメモを１ヶ月分保存する機能
- いざというときにケアマネジャーなどへ見せるためのPDF出力機能

### 本リリースで作る機能
- 過去の記録の推定グラフ機能
- ケアマネジャー等と画面上で連携、共有できる機能。PDF化して印刷、持参する手間をなくす。
- 任意でオン/オフを切り替えられるリマインド通知（記録忘れのケアとプレッシャー軽減のため、自分で切り替えられる形を検討）

### ※記録の保存期間について
- MVPでは、無料で運用、提供できる範囲に絞るため、記録の保存期間は1ヶ月分としています。
- 必要なタイミングでPDF出力して手元に保管しておくことで長期的な変化の確認や共有にも活用できるようにしています。
- 専門職への共有や長期的な変化の把握でより長い期間の記録が必要になるケースも想定しており、今後サービスが普及した際にはサブスクリプションなどを通じて保存期間の延長へ拡張していくことを検討しています。

### ※認知症機能チェックについて
- 設問は公的機関や専門機関が公開しているチェックリストなどを参考に作成する予定です。
- 本チェックは医療行為や医学的診断を目的としたものではなく、あくまで気づきやきっかけとする「診断ではない」旨を画面上で明記します。

## 8. このアプリの懸念点とその対策

- 何が問題になりそうか：記録の継続
- なぜそう思うか：日々の介護疲れで細かい記録をつけること自体が億劫になってしまうため
- そのために考えている対策：挫折しないよう入力はワンタップで選べる１日１回、必要最低限の３項目に絞り込みました。また言葉にしづらい日々の小さな変化もケアマネジャー等が知りたい情報をワンタップですぐに書き残せるメモ機能を実装し負担を極限まで減らしました。

## 9. 今後の展開・発展の方向性

- ユーザーが使い続ける理由：入力は1日1回、選択式の３項目（食事、睡眠、機嫌）のみ。メモには迷わないよう知りたい情報がタップで自動入力できる仕組みになっている。細かな血圧測定や服薬のような義務感やプレッシャーを排除した簡単さにより負担なく続けられる。
- 続けることで何が変わるのか：日々の記録自体が孤立しがちな家族にとって安心材料になる。
- データが溜まると何ができるのか：認知症の親の変化を可視化できるため次の対応や相談がスムーズになる。
- 他の人と関わる余地はあるのか：家族間でのトラブルやストレスを生む共有機能はあえて持たせない。その代わり記録したデータやPDFを通じてケアマネジャー等の専門職と状況を共有し適切な支援を引き出すための連絡ツールとして発展させる。
- 運用・仕組みで価値を出せないか：登録不要でまずチェック機能から始められる低ハードルな動線設計と、いざというときプロへ共有できる仕組みにより社会全体で支えるセーフティネットとして価値を出す。

### 今考えている発展案
- 機能追加の方向性：介護商品や支援サービス情報の案内。情報面からも家族をサポートする。
- UI・体験の改善：アプリを使用する人の好みや利用する時間帯を考慮し、画面のトーンを自分で選んで切り替えられる機能を実装する。
- 機能以外の工夫：SNSを通じて存在を届ける。気軽に試せるという心理的ハードルの低さを伝える。
