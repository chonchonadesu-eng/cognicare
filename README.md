このアイデアの元になった

▼
７年間介護の現場で働いている中で、
日々の仕事量の多さと人手不足で、目の前のケアをこなすだけで精一杯の現実を目の当たりにしました。
その中で紙の手続きや電話での連絡など、昔ながらの非効率な業務が残る現場の限界を知る一方で、２４時間３６５日自宅で介護を背負わなければならないご家族の負担や孤独感は、現場の比ではないことを痛感していました。

自宅で介護をする家族が、この手軽なアプリで日々の変化を無理なく記録し、必要な時にはPDFで専門職や関係者へスムーズに提示できる。そうすることで、家族が抱える負担や不安を軽減できるのではないかと思ったのが、このアプリを作るきっかけです。
